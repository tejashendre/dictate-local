# --- corrections: heard -> wanted -------------------------------------------
# Three layers deal with a term coming out wrong, in this order:
#
#   1. initial_prompt biases decoding toward the terms above. Soft, and it
#      does most of the work.
#   2. near-miss snapping fixes spellings that are close to a term above.
#      "Arbeitsugnis" and "Arbeitsuegnis" both land on Arbeitszeugnis without
#      anyone writing a rule, which matters because the exact mangling varies
#      run to run.
#   3. these explicit rules, for what neither of the above can reach.
#
# So you rarely need a rule here. Add one when the misheard word is too short
# for snapping (under 6 characters), or when it is a real English word that
# snapping deliberately refuses to touch.
#
# "Deami" is the standing example: five characters, so snapping skips it.
Deami -> DEAMIE
Deamy -> DEAMIE
