# CUDA runtime for the GPU path.
#
# ctranslate2 ships cudnn64_9.dll but NOT cublas64_12.dll, and this machine had
# no CUDA toolkit, so the GPU path failed. It failed in a way worth knowing
# about: WhisperModel(...) constructed fine on CUDA and the process only fell
# over later inside transcribe(), when the encoder first touched cuBLAS.
#
# dictate_core.enable_cuda_dlls() puts this wheel's directory on PATH before
# faster_whisper is imported. os.add_dll_directory is NOT enough - ctranslate2
# loads the DLL with a plain LoadLibrary, which searches PATH.
#
# Roughly 630 MB installed. Skip it and set DICTATE_DEVICE=cpu if you do not
# want the GPU path; everything still works, at about 2.5x realtime instead
# of 11x.
nvidia-cublas-cu12
